# Dashboard de Recursos Humanos – Análisis con Excel Avanzado y Power BI
Este proyecto presenta un análisis de datos de Recursos Humanos utilizando Excel Avanzado y Power BI, con el objetivo de evaluar la salud organizacional a través de KPIs clave y visualizaciones interactivas.

Objetivo:
Analizar información del personal para identificar tendencias, detectar problemas de ausentismo y deserción, y apoyar la toma de decisiones basadas en datos.

Herramientas
Excel Avanzado: limpieza, modelado inicial y preparación de datos.
Power BI: modelado con DAX, relaciones, dashboard interactivo e informe ejecutivo.

Contenido del Dashboard:
KPIs: Empleados activos, tasa de ausentismo, deserción, satisfacción.
Segmentación por género, estado civil y grupo étnico.
Análisis por departamento, fuente de reclutamiento y performance.
Tendencias de ausentismo y años-persona.

Resumen Ejecutivo:
El análisis revela patrones importantes en diversidad, antigüedad, ausentismo y satisfacción. Se identifican áreas que requieren intervención y mejoras en procesos de bienestar y reclutamiento.
